# Glorious Times Standards Nursery and Primary School website

Responsive animated static website made with HTML, CSS and JavaScript.

## Files
- `index.html`: website content
- `css/style.css`: layout, colours, responsive styling and animations
- `js/script.js`: mobile menu, Academics dropdown and reveal effects
- `images/school-logo.png`: your exact uploaded logo image

## Preview
Extract the ZIP, open the folder in VS Code, then open `index.html`. With the VS Code Live Server extension, right-click `index.html` and select **Open with Live Server**.

## Publish on GitHub Pages
Upload all files inside this folder to a GitHub repository. Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.

## Before publishing
The photos currently use external Unsplash URLs and need internet access. Replace them with school-approved photos when ready. Contact details reflect the information previously provided. WhatsApp buttons open WhatsApp; this version does not yet connect to an online admissions database. The navigation has no Campuses dropdown; the Academics dropdown remains.
